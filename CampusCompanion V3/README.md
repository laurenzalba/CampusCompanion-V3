# Campus Companion - Exercises 1, 2, and 3

This project extends the working Campus Companion app with Exercise 3.

Included:
- Existing welcome screen, Explore Campus flow, name/switch/role/date/guest inputs
- Campus Announcements button below Explore Campus
- Six hardcoded CampusAnnouncement records
- UITableViewController with reusable custom AnnouncementCell
- Icon, title, category/date subtitle, and priority indicator
- Urgent announcements use a red warning icon/priority text
- Row selection passes the tapped announcement to DetailViewController
- Detail displays title, category, date, priority, and Posted By
- Existing Explore Campus detail behavior remains intact
- Bundle identifier: edu.feutech.mad2.CampusCompanion

Open CampusCompanion.xcodeproj, choose an iPhone Simulator, and Run.
